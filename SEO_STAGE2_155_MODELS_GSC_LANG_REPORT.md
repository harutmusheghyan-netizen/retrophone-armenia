## 4. Google Search Console — действия после владельческого подтверждения

Указанные сайты — **разные субдомены vercel.app**. Рекомендуемый путь: создать/проверить **три независимых свойства типа «Ресурс с префиксом URL»** в https://search.google.com/search-console/ :
1. `https://retrophone-armenia.vercel.app/` → `sitemap.xml`.
2. `https://retrophone-armenia-catalog.vercel.app/` → `sitemap.xml`; **после развёртывания** → также `sitemap-additions.xml`.
3. `https://retrophone-armenia-history.vercel.app/` → `sitemap.xml`.

Подтверждение владения выполняется пользователем через Search Console (метатег/HTML-файл/иной допустимый способ). У владельца может быть уже подтверждённый доступ — сначала проверить. У нас **нет подтверждённого доступа к Google Search Console**, поэтому нельзя заявлять об отправке sitemap, индексации или реальных показах. При подключении аналитики можно получить данные кликов и покрытия через поддерживаемый источник. Данные поискового индекса не выводятся из одного HTTP 200.

## 5. Локализация — оставшиеся расхождения

**Истории брендов:** проверенная страница `/Nokia.html?lang=hy` отдаёт `<html lang="hy">`, армянский заголовок, свой canonical и 3 hreflang. Не сломать.

**Каталог:** `/phones/nokia/1110?lang=hy` отдаёт армянский HTML/title, но canonical указывает на русскую страницу и hreflang отсутствует. Исправление кода для полноценного перевода находится в другом безопасном PR #18, с успешным QA; в production пока не установлено.

**Главная:** `/?lang=hy` возвращает `<html lang="ru">` и русский title.

**Новости:** `/news/?lang=hy` и `/news/?post=google-gemini-omni-1-2-flash-video-2026&lang=hy` возвращают русский исходный HTML/title и canonical обзорной страницы `/news/`. Хотя браузер может переключать язык JavaScript-ом, **сейчас нельзя выдавать эти URL за готовые индексируемые армянские версии через hreflang**. Критически важно внедрить серверный HTML для уникальных опубликованных новостей (заголовок, статья, дата, исходный источник), уникальные canonical на каждую статью и RU/HY/EN альтернативы. Менять только код/SEO, без изменений утверждённого оформления; сначала тестовая сборка и сверка снимков экрана.
