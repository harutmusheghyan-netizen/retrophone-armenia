## Correctness checks in server code

- `retro_news_preview_draft` requires an authenticated `auth.uid()` present in `admin_users`, and a matching `revision`.
- `retro_news_publish_draft` repeats the owner check; requires last preview to match current revision; validates content, provenance, photo license, and minimum RU/HY/EN lengths.
- Draft revision guard resets the preview state when material content changes.
- The positive SQL test was explicitly inside `BEGIN ... ROLLBACK`. It is **not** a real successful admin login; it only exercises DB-side behavior.
