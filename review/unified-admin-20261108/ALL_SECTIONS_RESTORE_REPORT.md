# RetroPhone Armenia — восстановление существующих данных во всех разделах админки

**Дата:** 8 ноября 2026.  
**Исходный рабочий сайт:** `retrophone-armenia.vercel.app`, Vercel `dpl_9ZhCYFqWg1nheVfU2yxm97ovMRTu`.  
**До:** эталонная админка `retrophone-admin-etalon.vercel.app`, Vercel `dpl_3ZGY3cL4tfVBndMSF4Cvng2ce58c`; в «О нас» восстановлены 87 полей, но другие разделы показывали только частичные данные / пустой CMS.  
**После в коде (ещё не развернуто):** ветка `fix/admin-all-sections-existing-data-20261108`, PR #16.

## Выявленные причины

1. **Истории брендов.** Действующая панель брала `brands.short_history`, но полная утверждённая история жила на самостоятельном сайте `retrophone-armenia-history.vercel.app`; поэтому три языковых поля были пусты или содержали только короткий русский фрагмент.
2. **Главная.** Панель читала лишь пустую редакционную таблицу `cms_published_blocks`, тогда как действующие строки главной находятся в локализованном `T` и `ABOUT_I18N` статического HTML.
3. **Каталог.** Описание и переводы загружались из Supabase, но существующая фотография, атрибуция, характеристики и источник не показывались; пустые переводы могли перекрывать заполненные ранее значения.
4. **Новости.** Уже существующий редактор читает `retro_news_posts` и `retro_news_edit_drafts`; логика списков, фото и видео сохранена.
5. **«О нас».** 29 исходных текстовых ключей × RU/HY/EN и существующая фотография уже восстановлены в предыдущем эталоне v2, сохранены без изменения.

## Восстановленные исходники

- `brand-etalon-part-1.json` — полные утверждённые RU/HY/EN истории Nokia, Samsung, Sony Ericsson, Motorola, LG.
- `brand-etalon-part-2.json` — полные утверждённые RU/HY/EN истории Siemens, Alcatel, Philips, Ericsson, Sony.
- **30 оригинальных страниц** на трёх языках, включая исходный HTML и извлечённый видимый текст; не машинный перевод заново.
- `brand-original-logos.json` — 10 существующих логотипов из утверждённых исторических страниц с исходными ссылками Wikimedia Commons. В редакторе показываются **только для просмотра**.
- `homepage-etalon-data.json` — исходные локализованные строки T и ABOUT_I18N, включая заголовок и подзаголовок героя. Для `news_heading` доступна только оригинальная подпись навигации «IT-новости», не подтверждён отдельный заголовок блока новостей; UI явно отмечает это.
- Каталог читает существующие `phone_models`, `phone_model_translations`, `products`, фото, источник, спецификации. Фотография не перезаписывается, если новая не указана. Цена/количество меняются только после явного включения редактирования остатков.
- Приоритет данных: **оригинальные источники → записи опубликованного CMS → текущий сохранённый черновик**.

## Защита от потери данных

- Загрузка исходного источника обязана пройти проверку; при отказе серверного или статического источника кнопки сохранения/публикации остаются отключены.
- SQL `cms-save-home-subtitle.sql` добавляет в разрешённые поля только существующие `subtitle_ru/hy/en`. Предыдущая функция сохранена в `cms-save-before-home-legacy-fields.sql`.
- SQL `cms-brand-preserve-short-history.sql` предотвращает перезапись короткой истории бренда полным текстом в поле `brands.short_history`. Полная трёхъязычная версия ожидает проверенного адаптера статической страницы. Предыдущая функция сохранена в `cms-publish-before-brand-preservation.sql`.
- По завершении теста в Supabase: **10 брендов, 870 моделей, 26 опубликованных новостей, 0 товаров в `products`, 1 существовавший черновик каталога для модели 381, 0 записей опубликованного CMS**. Черновик 381 сохранён.
- Публикация бренда и главного hero с сохранением субтитров проверена в транзакции с `ROLLBACK`; никаких реальных новостей, изображений, цен, страниц и истории брендов не изменилось.
